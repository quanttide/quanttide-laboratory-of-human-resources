# 开发者指南

本目录描述量潮招聘系统"理想中的样子"——从产品功能角度出发，想象一个没有邮件依赖的招聘系统应该具备什么能力。

- [HR 视角](./hr-experience.md) - HR 如何管理系统
- [流程管理](./workflow.md) - 招聘流程如何运转
- [通知系统](./notification.md) - 消息如何触达

## 核心目标

**让邮件从招聘流程里消失。**

当前系统：
- 候选人通过邮件接收通知（问卷、邀请、考核）
- HR 通过邮件文件夹管理候选人状态
- 数据散落在飞书多维表格和邮件中

理想系统：
- 候选人在系统内完成所有操作
- HR 在系统内看到所有候选人的状态
- 所有数据集中在一个地方

# 流程管理

## 流程全景

```
投递 → 问卷 → 审核 → 邀请 → 入群 → 考核 → 评估 → Offer
```

每个阶段都有明确的进入条件和退出条件。

## 阶段详解

### 投递阶段

**进入条件**：候选人提交投递

**系统行为**：
- 记录候选人信息
- 存储简历材料
- 自动发送问卷通知

**退出条件**：候选人完成问卷

---

### 问卷阶段

**进入条件**：候选人收到问卷通知

**系统行为**：
- 提供问卷链接
- 记录问卷提交时间
- 通知 HR 有新问卷提交

**退出条件**：
- 候选人提交问卷 → 进入审核
- 超过 3 天未提交 → 标记为未完成

---

### 审核阶段

**进入条件**：候选人提交问卷

**系统行为**：
- 展示问卷答案给 HR
- 提供审核操作（通过/拒绝）

**退出条件**：
- HR 审核通过 → 发送邀请
- HR 审核拒绝 → 通知候选人

---

### 邀请阶段

**进入条件**：HR 审核通过

**系统行为**：
- 发送实训邀请通知
- 提供群二维码
- 记录候选人是否入群

**退出条件**：
- 候选人入群 → 进入考核
- 超过 7 天未入群 → 标记为未响应

---

### 考核阶段

**进入条件**：候选人加入实训群

**系统行为**：
- 发送考核通知
- 提供众包任务和课堂资料链接
- 记录候选人是否退群

**退出条件**：
- 候选人提交考核成果 → 进入评估
- 候选人退群 → 标记为退出

---

### 评估阶段

**进入条件**：候选人提交考核成果

**系统行为**：
- 展示考核成果给 HR
- 提供评估操作（通过/拒绝）

**退出条件**：
- HR 评估通过 → 发送 Offer
- HR 评估拒绝 → 通知候选人

## 状态追踪

每个候选人都有清晰的状态线：

```
张三的状态线
──────────────────────────────────────────────────
✓ 投递（1月10日）
✓ 问卷已发送（1月10日）
✓ 问卷已提交（1月12日）
✓ 审核通过（1月13日）
✓ 邀请已发送（1月13日）
✓ 已入群（1月14日）
○ 考核中...
──────────────────────────────────────────────────
```

## 退出机制

候选人可以在任何阶段主动退出：
- 退群 = 退出考核流程
- 系统自动标记状态
- HR 可以看到退出原因（如果有）

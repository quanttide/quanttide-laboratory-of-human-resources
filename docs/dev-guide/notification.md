# 通知系统

## 设计原则

**所有通知都在系统内完成，不再依赖邮件。**

## 候选人收到的通知

| 时机 | 通知内容 | 说明 |
|------|----------|------|
| 投递后 | 请填写准入问卷 | 附问卷链接 |
| 问卷提交后 | 问卷已收到 | 告知等待审核 |
| 审核通过后 | 欢迎加入实训基地 | 附群二维码 |
| 进入考核后 | 你已进入考核阶段 | 附考核说明 |
| 考核通过后 | 恭喜通过考核 | 告知后续流程 |
| 考核未通过 | 感谢参与 | 礼貌告知 |

## HR 收到的通知

| 时机 | 通知内容 | 说明 |
|------|----------|------|
| 新投递 | 有新的候选人投递 | 附候选人信息 |
| 问卷提交 | 有候选人提交问卷 | 附查看链接 |
| 候选人入群 | 有候选人加入实训群 | 附候选人信息 |
| 考核提交 | 有候选人提交考核 | 附查看链接 |
| 候选人退群 | 有候选人退出考核 | 附候选人信息 |

## 通知特性

- **实时推送**：新通知立即显示，无需刷新
- **已读状态**：未读通知有明显标记
- **操作入口**：通知中直接包含操作按钮
- **历史记录**：所有通知可查

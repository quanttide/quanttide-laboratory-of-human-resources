# 候选人视角

## 投递

候选人访问招聘页面，填写基本信息，上传简历，提交投递。

提交后，系统自动发送通知：「感谢投递，请先完成准入问卷。」

## 问卷

候选人在系统内看到问卷链接，点击进入填写。

填写完成后，系统自动记录，并发送通知：「问卷已收到，请等待审核。」

## 实训邀请

审核通过后，候选人收到通知：「你已通过初筛，欢迎加入量潮实训基地。」

通知中包含：
- 实训基地群二维码
- 考核规则说明
- 预期时间安排

候选人扫码入群，修改昵称，开始实训。

## 考核

进入考核阶段后，候选人收到通知：「你已进入考核阶段。」

通知中包含：
- 考核方式说明
- 众包任务链接（可选）
- 课堂资料链接（可选）

候选人自主选题，提交成果。

## 结果

考核结束后，候选人收到最终通知：
- 通过：「恭喜，你已通过考核，后续流程将由 HR 联系你。」
- 未通过：「感谢参与，期待未来有机会合作。」
